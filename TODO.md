# PDF Toolkit — MVP outcomes

## 1. Home and file intake
- [x] Provide a clear home screen for choosing a PDF task, with original branding and straightforward file-selection and drag-and-drop flows.

## 2. Merge PDFs
- [x] Merge multiple PDF files, display them in a reorderable list, and generate one combined PDF.

## 3. Split and extract pages
- [x] Split a PDF by page ranges or extract individually selected pages into a new PDF.

## 4. Organize PDF pages
- [x] Organize PDF pages with visual thumbnails and controls to reorder, rotate, and delete pages before exporting the result.

## 5. Convert images to PDF
- [x] Convert one or more JPG or PNG images into a PDF, with image reordering and basic page sizing or orientation options.

## 6. Compress PDF
- [x] Compress PDFs with practical quality presets and a clear before-and-after file-size summary, subject to reliable browser-based compression limits.

## 7. Export pages as images
- [x] Export selected PDF pages as downloadable image files with a choice of JPG or PNG.

## 8. Reliable interaction states
- [x] Provide clear validation, progress, error, reset, and download states so files can be processed reliably without confusing dead ends.

## 9. Extensible scope
- [x] Keep OCR and Office-format conversion visibly outside the initial release scope while structuring the toolkit so additional tools can be added later.
